Our approach

Zero Trust, applied to Kubernetes.

Nothing is trusted by default — not users, not pods, not images. Every fix maps to one of four rules.

🪪

Verify every identity

Least-privilege RBAC, no shared cluster-admin, scoped service accounts.

🚧

Deny by default

Network policies so workloads only talk to what they must.

✍️

Run only what's signed

Signed, scanned images enforced at admission.

👁️

Watch at runtime

Audit logging and Falco detection so you know when something is wrong.

Do you need admin access?

No. Reviews use a read-only account. Changes only happen in a Hardening Sprint, with your approval.

Do you work outside Canada?

Yes — CloudKanata is based in Toronto and works remotely with teams anywhere.

How does payment work?

Fixed-price packages are invoiced up front (Stripe); sprints can be split 50/50.

Is this a pen test?

No. It's a configuration and architecture review against CIS and Kubernetes best practice — the fixes that close the most risk fastest.
